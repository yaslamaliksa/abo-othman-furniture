# ابو عثمان لغرف النوم والاثاث

ملفات المتجر جاهزة للنشر عبر GitHub Pages. تحتوي على ١١ موديلًا و٥٨ صورة، ونموذج اختيار اللون والمقاس وإرسال تفاصيل الحجز عبر واتساب.

## النشر على GitHub Pages

1. فك ضغط الحزمة. ارفع الملفات والمجلدات المستخرجة إلى جذر مستودع GitHub على فرع `main`. تأكد من وجود `index.html` ومجلد `assets` في المستوى نفسه.
2. افتح **Settings → Pages** في المستودع.
3. اختر **Deploy from a branch** ضمن **Source**. اختر فرع `main` ومجلد `/ (root)`، ثم اضغط **Save**.
4. يظهر رابط المتجر في صفحة **Pages** بعد اكتمال عملية النشر.

## معاينة المتجر على جهازك

شغّل الأمر التالي داخل المجلد المستخرج ثم افتح `http://127.0.0.1:8000` في المتصفح.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

أسماء الموديلات وأوصافها وخيارات الألوان والصور موجودة في `catalog.js`.
